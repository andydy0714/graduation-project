# 基于智能体与几何重演的机加工艺规程验证方法研究

本科毕业设计（许真玮 2023110080，指导教师 聂兰顺）。

以工艺规程文本、毛坯 STEP 模型与成品 STEP 模型为输入，由智能体把工序工步描述转换为
参数化的材料去除操作，在几何内核上逐步布尔差重演各工序的中间几何形态，自动生成中间
工件附图与几何一致性检查结果，最终输出图文验证报告。

进度按 31 周推进，详见 `docs/毕设进度安排_31周.txt`。

## 目录

| 目录 | 放什么 | 是否进版本库 |
|---|---|---|
| `docs/` | 论文与开题报告、答辩 PPT、进度安排 | 是 |
| `data/` | 10 个典型工件的 毛坯/成品 STEP 与 工艺规程.txt | 是（数据集是实验载体） |
| `src/` | 全部代码 | 是 |
| `exp/` | 标注集、异常样本、回归用例、实验数据与结果表 | 是（结果表要留档） |
| `out/` | 中间 STEP 模型、操作日志、工序附图、验证报告 | 否（可随时重建） |

## 代码

| 文件 | 作用 | 状态 |
|---|---|---|
| `src/geokernel.py` | 几何内核封装：STEP 读写、布尔差、体积/包围盒查询、运算日志、数据集自检 | 已完成（W1） |
| `src/build_parts.py` | 按图样建 10 件工件的毛坯与成品 STEP | 已完成（前期） |
| `src/verify_steps.py` | 独立验收：换一条通道读回 STEP，核对有效性、体积、包围盒与布尔包含关系 | 已完成（前期） |
| `src/write_plan.py` | 把工序表按统一版式写成 工艺规程.txt | 已完成（前期） |
| `src/audit_dims.py` | 一致性核查：成品 STEP 实测直径/端面 vs 工艺规程文本数值 | 已完成（2026-10-05） |

后续加入：`geotools.py`（几何查询工具）、`operators.py`（材料去除算子库）、

`make_fig.py` / `report_gen.py`（附图与报告）。

## 运行

所有脚本都用 FreeCAD 自带的 Python（内含 Open CASCADE），在工程根目录下执行：

```bat
:: 几何内核 + 数据集自检（10 件工件，结果写入 exp/dataset_selfcheck.json）
"D:\FreeCAD 1.1\bin\python.exe" src\geokernel.py --selfcheck

:: 数据集独立验收（换 Import 通道读回，打印「验收通过」）
"D:\FreeCAD 1.1\bin\python.exe" src\verify_steps.py

:: 重建某件工件的毛坯/成品（不带参数则全部重建，输出到 data/）
"D:\FreeCAD 1.1\bin\python.exe" src\build_parts.py 输出轴

:: 数据集一致性核查（成品实测尺寸 vs 工艺规程文本，可带工件名过滤）
"D:\FreeCAD 1.1\bin\python.exe" src\audit_dims.py 活塞杆
```

## 数据

`data/` 下 10 个典型工件，取自《典型零件机械加工生产实例》（陈宏钧 主编，第 3 版，第 4 章）。
每个目录含 `毛坯_<拼音>.step`、`成品_<拼音>.step` 与 `工艺规程.txt`（工序号｜工序名称｜工序内容）。

建模约定：螺纹不建牙型（按大径车成光柱）、齿轮只做到齿坯、回转体上的键槽/退刀槽/锥面/
均布孔等局部特征按图样尺寸精确建出。

数据集状况（`exp/dataset_selfcheck.json`）：10 件全部通过有效性、体积守恒与包围盒包含检查；
其中 `调整偏心轴` 的毛坯减成品得到 2 块余料（底部余量 + 另一端偏心外圆环料），
属于偏心件正常情况，不是数据缺陷。

数据集正确性核查（2026-10-05，详见 `exp/数据核查记录.md`）：把 10 件的模型与 工艺规程.txt、
书上原图原表逐件三方对照，**真错只有活塞杆右端母线**（漏 1:20 锥面、φ36 切槽被建成 60mm
长，应为 5mm），已修复重建并复验；其余 9 件无错。另有 2 条待确认项（柱塞退刀槽轴向位置、
定位销轴小头分段）登记在 `exp/标注规范.md` §六，不计对错。

注意 `verify_steps.py` 与建模共用同一条母线算理论值，**无法发现母线本身写错**（活塞杆的错
就是这样漏掉的）；几何实测与图纸文本的对照要靠 `audit_dims.py` + 人工核对。
