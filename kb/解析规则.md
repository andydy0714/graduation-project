# 解析规则

供解析智能体使用。**全部写成与具体工件无关的形式**——规则里出现的尺寸都只是示例格式，
不是任何一件工件的答案。粒度按工序计（一条工序算一次，见 `../exp/标注规范.md` §一）。

三类：**R1–R7 模型语义**（文本描述 → 几何上建不建）；**R8–R13 数值口径**（文本没给数、
或给的数不是成品尺寸时怎么办）；**R14–R16 系统契约**（什么算通过、什么必须报待确认）。

## R1–R7 模型语义

| 编号 | 规则 | 说明 |
|---|---|---|
| R1 | **螺纹按名义大径建光杆，不建牙型** | 文本出现 M4 / M8 / M20 / M27 / M30 / M39，或"车螺纹 / 套螺纹 / 板牙套 X"时，车成光圆柱（M20→φ20、M27→φ27、M30→φ30、M39→φ39）。管螺纹（R / G 系列）建**外圆锥面**、不建牙型 |
| R2 | **齿形加工只做到齿坯** | 滚齿 / 插齿 / 铣齿等 → 不建齿廓；齿顶圆就是该处外圆（d_a = m·(z+2) 可作校核），分度圆、齿根圆是参考尺寸，不构成实体 |
| R3 | **中心孔不体现** | "钻中心孔 A2 / A2.5 / B2.5""修研两端中心孔" → 只为定位，几何上不建 |
| R4 | **微去除与工艺性特征不体现** | 研磨、去毛刺、尖角倒钝、渗氮层 / 发蓝层、标记 → 不建。倒角只在文本给出 C 值时才建（未注倒角见 R8） |
| R5 | **毛坯 = 下料 / 锻造 / 铸造之后的形状** | 下料、锻造、铸造、清砂属非去除类，不参与重演。否则"下料 φA×L₁ → 锻造 φB×L₂"这种文本会变成一道无解的去除工序（自由锻后长度反而变大是常见的） |
| R6 | **连下件只建单件** | 文本出现"n 件连下"时，毛坯取单件长度：文本里"切下 / 切断保证总长 X"的 X，或 下料长度 ÷ n |
| R7 | **工艺凸台是中间态** | 中心孔处的工艺凸台（车出 → 线切割 / 铣掉）在毛坯里没有、在成品里也没有；重演时会先做出来再切掉，两侧 STEP 都看不到它，属正常，不是缺料 |

## R8–R13 数值口径

| 编号 | 规则 | 说明 |
|---|---|---|
| R8 | **缺值就查几何，不许猜** | 最终尺寸若文本没给（"各部""至图样尺寸""按图样要求"），调几何查询工具从**成品**量取；粗加工目标按第 3 级（"见圆 / 见平即可"**句中给了数就用该数**，没给数则只要求车光、不给尺寸；"留余量 X"→ 成品 + X）。四级优先全文见 `../exp/标注规范.md` §三 |
| R9 | **螺纹段给的直径是坯料外径** | 文本给螺纹段的直径数值（常带偏差，形如 `φ19.7~19.85`、`φ30(+0.25/+0.15)`）是**螺纹加工之前**的坯料外径，不是成品尺寸。模型按名义大径建，这些数值记为**工艺中间尺寸**：不参与偏差判定，也不算"规程漏写" |
| R10 | **工序链里的中间尺寸不是最终尺寸** | 同一部位在多道工序里反复出现（切槽 → 切除工艺凸台 → 磨端面）时，以**最后一道**为准，前面出现的是当时的中界面尺寸。看到两处数值差一个磨削量（如 4.5 与 4），先按工序链解释，不要判矛盾 |
| R11 | **余量方向不明按收敛处理** | 文本说"留加工余量 / 留磨削余量 X"未写明是直径还是单边时，按"终序必须收敛到成品尺寸"处理；中间尺寸取值不影响终态比对 |
| R12 | **公差取名义值 / 中值，阈值 0.1mm** | 目标尺寸取名义值（如 `φ20(+0.4/+0.3)` 取 φ20.35）；几何一致性判定阈值 0.1mm（可配置） |
| R13 | **配磨类以成品为准** | 文本写"与某配对件配磨""保证间隙…"而配对件不在输入内时，以**成品 STEP** 为准，不引入第二个标准，也不报"缺件" |

## R14–R16 系统契约

| 编号 | 契约 |
|---|---|
| R14 | **命中 R1–R7 的工序要报"几何上不体现"，不是报错**：这类工序重演前后体积不变，输出应写明"本工序在模型上不体现（依据 R1/R3/…）"，不得判为异常 |
| R15 | **规则没覆盖就报待确认，不许猜**：遇到 R1–R13 都没覆盖的描述（新零件的新写法），必须输出**待确认项**并说明缺什么；不得默认取一个值然后判通过。**"可解释的拒绝"是正确行为，"看起来通过的错答案"是最严重的失效** |
| R16 | **两个方向都要成立才算验证器有用**：正常样本零误报 **且** 异常样本全部报出。只会通过、不会失败的检查等于没检查（异常样本集见进度安排 W15） |
