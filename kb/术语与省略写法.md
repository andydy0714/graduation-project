# 术语与省略写法对照表

规程里"话没说完"的地方怎么读。**写法示例只用来识别句式，不是答案**——解析时以输入文本
与几何查询结果为准，不得把这里的示例数值当成某件工件的目标值。

## 一、数值省略

| 写法 | 含义 | 处理 | 关联规则 |
|---|---|---|---|
| 「见平即可」「见圆即可」 | 去毛坯黑皮 | **句中给了数就用该数**（"φ88mm 见圆即可" → φ88）；没给数则只要求车光，不给目标尺寸 | R8 |
| 「至图样尺寸 X」「按图样要求」 | 最终尺寸 | 同句给了数用该数；没给数 → 调几何工具从成品量取 | R8 |
| 「各部」「其余各部」 | 该端所有外圆 / 端面 | 逐个部位从成品量取 | R8 |
| 「留精加工余量 X」「留磨削余量 X」「留加工余量 X」 | 中间尺寸 | 成品尺寸 + X（方向未写明按 R11） | R11 |
| 「φXX mm 处」「距 XX 面 Ymm 处」 | 定位尺寸 | 从该面起量，注意该面本身后续是否还会被磨掉 | R10 |
| 「按 GB/T 145 / 7306 …」 | 标准件 / 标准螺纹 | 按标准取值，不建标准件细节（如中心孔） | R3 |

## 二、工序关系

| 写法 | 含义 | 处理 | 关联规则 |
|---|---|---|---|
| 「倒头装夹」「倒头」 | 调头，基准与工序坐标系翻转 | 生成工序坐标系变换；后续描述的是另一端 | — |
| 「接上序 φXX mm」 | 与上一道工序的同一尺寸相接 | 同一目标尺寸，只是换了装夹方向，不是新尺寸 | — |
| 「两顶尖装夹」「一夹一顶」「中心架支承」 | 装夹方式 | 不影响几何，只影响基准与刚性（工序 6「使用跟刀架」同理） | — |
| 「切下 / 切断，保证总长 X」 | 从连下料上切出单件 | 毛坯长度取 X | R6 |
| 「n 件连下」 | 一根料做 n 件 | 只对单件建模 | R6 |
| 「工艺凸台」 | 中心孔处的定位凸台 | 中间态：先车出、后切除，毛坯与成品都没有 | R7 |
| 「垫上铜皮」 | 夹持保护 | 不影响几何 | — |

## 三、加工方法与特征

| 写法 | 处理 | 关联规则 |
|---|---|---|
| 「钻中心孔 A2 / A2.5 / B2.5」「修研两端中心孔」 | 定位孔，几何上不建 | R3 |
| 「车螺纹 M30-6g」「套螺纹 M20-7h」「板牙套 R1½」 | 牙型不建；普通螺纹按名义大径建光杆，管螺纹建外圆锥面 | R1 |
| 「滚齿（m=…，z=…）」「插齿」 | 只做到齿坯 | R2 |
| 「拉深 0.5mm、长 24mm 润滑槽」 | 内孔环形槽：槽底孔径 = 孔径 + 2×深度，长度取给定值，按环形槽布尔差 | R8 |
| 「倒角 C1」「倒内角 C1」「各部倒角」 | 有 C 值就建；「未注倒角」按技术要求或从成品量取 | R4 / R8 |
| 「车小头 φXX 处锥度」「车 XX 与 YY 连接的锥度」 | 部位给了、数值没给 → 从成品量取锥面两端直径与长度 | R8 |
| 「切槽 5mm × φ36mm」 | 槽宽 × 槽底直径 | R8 |
| 「钻 φXX mm 孔深 YY mm」「钻 2×φ6mm 孔」 | 孔直径 × 数量，深度 YY | R8 |
| 「倒坡口 120°，控制坡口最大直径 φXX」 | 锥形坡口，按角度 + 最大直径建 | R8 |
| 「与配套件配磨，保证间隙 X」 | 配对件不在输入内 → 以成品 STEP 为准 | R13 |
| 「研修 / 研配 / 研磨」 | 微去除（垂直度、粗糙度）→ 不建 | R4 |
| 「去毛刺」「尖角倒钝」 | 微去除（边缘毛刺 / 锐边）→ 不建 | R4 |

## 四、非去除类（报告原样抄写，不附图、不给验证结论）

热处理（正火 / 调质 / 淬火 / 回火 / 渗氮）、冷处理、划线、检验、探伤、标记、入库、下料、
锻造、铸造、清砂、发蓝、涂油包装。分类与报告呈现格式见 `../exp/标注规范.md` §二。

## 五、遇到表里没有的写法

不许按"看起来像"去解释 → 按 R15 报**待确认项**并说明缺什么；人工确认后回填这张表
或 `解析规则.md`（回填前先过 `kb/README.md` §边界里那条标准问题：它是规则还是答案）。
